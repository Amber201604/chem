# 世界真实运行知识（World Knowledge）

本文件夹专门记录**与课件模型对应、但属于真实世界物理/化学事实**的知识点。  
课件里的 Bohr 轨道、动画简化可以有教学取舍；这里写的是世界实际怎么运行。

## 约定

1. **课件简化 ≠ 错误**：例如电子壳层画成平面圆环是教学模型；真实原子是量子态。
2. **中子数**默认取该元素在教学中最常用的稳定同位素（如 Fe → \(^{56}\mathrm{Fe}\)）。
3. 有新事实时：新增 `.md` 或更新对应文档，并在本索引表加一行。
